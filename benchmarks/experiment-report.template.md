# OrderPage 비교 실험 보고서 양식

이 파일은 **빈 양식**이다. 실제 날짜·계정·리소스·원본 경로와 측정값을 채우기 전에는 성능 결과가 아니다. 비밀번호·토큰·원시 plan JSON·사용자 식별자는 넣지 않는다.

| Backend commit·불변 ECR digest A/B | 미측정 |
| Infra commit·GitOps PR·배포 전략/requests/HPA | 미측정 |

동일 지표의 기준 중앙값과 변경 후 중앙값을 별도로 계산한다. 낮을수록 좋은 지표의 개선율은 `(기준 중앙값 - 변경 후 중앙값) / 기준 중앙값 × 100`이고, 처리량처럼 높을수록 좋은 지표는 `(변경 후 - 기준) / 기준 × 100`이다. 기준이 0이거나 누락되면 개선율을 계산하지 않는다. 실패 횟수·최대 연속 장애시간·복구 실패를 함께 보고한다. CloudWatch 알림은 SNS 발행과 이메일 **수신** 시간을 구분한다.

## 판정과 비용

- 관찰한 변화와 대체 설명(부하 발생기 한계, Pod Pending, DB 병목, 지표 결측): 미측정
- 조건 통제 실패 또는 재실험 사유: 미측정
- 가동 시작/종료 UTC·Cost Explorer 조회 시각·계정 전체/태그 범위·Estimated 여부: 미측정
- 결과 발표에 사용할 그래프·원본 보관 위치: 미측정
