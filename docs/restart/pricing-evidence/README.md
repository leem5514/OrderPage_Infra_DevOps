# 가격 근거 JSON — 비용 계산에 사용한 단가

이 JSON은 **AWS 가격표에서 조회한 단가·SKU·단위·조회 시각**을 보관합니다. Terraform 설정이나 청구 내역이 아니며 AWS에 업로드할 파일도 아닙니다. 사람이 읽는 예측·48시간 운영 계획은 [비용 문서](../costs.md) 하나로 모았습니다. [문서 지도](../README.md)

| 파일 | 용도 | 현재 사용 여부 |
|---|---|---|
| [seoul-2026-11-27.json](seoul-2026-11-27.json) | 최근 서울 리전 단가 17개와 출처. 시간/GB/월 등 단위를 포함 | **현재 계산기와 lab-costs 테스트가 읽는 입력** |
| [seoul-2026-11-06.json](seoul-2026-11-06.json) | 초기 아키텍처 검토 당시 AWS 서울 단가와 출처 | 과거 예측을 설명하는 증거만 보존. 현재 계산에는 사용하지 않음 |
| [jenkins-seoul-2026-11-08.json](jenkins-seoul-2026-11-08.json) | Jenkins EC2 선택 당시 m6i.large·gp3 단가 | 과거 Jenkins 선택 근거. 현재 계산에는 사용하지 않음 |

예를 들어 seoul-2026-11-06.json의 `catalogs[].rows`는 당시 조회한 상품 가격 행입니다. `sku`는 상품 식별자, `pricePerUnit.USD`는 단위당 달러 가격, `retrievedAt`은 조회 시각입니다. 필드 구조는 파일마다 다르며 파일명 날짜가 가동 날짜는 아닙니다.

현재 계산은 저장소 루트에서 `node scripts/estimate-lab-costs.mjs`로 재현합니다. 네트워크·AWS 인증·apply를 호출하지 않습니다. 수량·사양과 사용량 가정은 계산기 및 비용 문서를 함께 확인하세요. 72시간 출력은 비교용이며 현재 운영 한도는 48시간입니다.

이전 estimate.mjs는 오래된 가정의 중복 계산기여서 삭제했습니다. 원본 JSON을 보존한 이유는 초기 예측과 현재 예측의 차이를 설명하기 위해서입니다. 단가를 갱신할 때는 출처·단위·조회일을 함께 보관하고 계산기와 테스트가 새 입력을 사용하도록 함께 변경합니다. 실제 청구액은 Cost Explorer 등 운영 결과로 별도 확인합니다.
