## 다음 순서 — 아직 실행하지 않음

배포 가능 시점은 **2026-11-28 16:00 이후(KST)**입니다. 예약 실행이 아니며 실제 시작·정리 시각은 아직 정하지 않았습니다.

1. CLI 임시 로그인, 지정 Role, 운영 PC IP 제한, 원격 state·정책과 최신 plan을 확인합니다. Budget/SNS를 준비할 적용 순서와 구독 수신 확인도 점검합니다.
2. 실제 진행 시각을 기록하고 최초 EKS 단계 apply를 실행합니다. 생성되는 유료 자원부터 과금되므로 운영 시간은 첫 apply 시작부터 보수적으로 계산합니다.
3. 실제 EKS OIDC issuer를 정책에 연결하고 전체 plan을 다시 검토합니다. 최초 단계에는 워커 노드와 운영자 access entry가 없으므로 kubectl 운영 준비 완료가 아닙니다.
4. 나머지 인프라, Jenkins·Argo CD, 앱·도메인·관측을 연결합니다. SNS 수신·Prometheus Targets·앱 기능을 확인합니다.
5. 기준값과 변경값을 동일 조건으로 측정하고 증거를 내보냅니다. 40시간 즈음 정리를 시작해 **48시간 전에 삭제와 잔여 자원 확인까지** 끝냅니다.

현재 19개 plan에는 Budget/SNS가 없습니다. Budget은 코드와 입력만 준비된 상태이며, 알림이 이미 활성화됐다고 가정해서 인프라를 켜지 않습니다. 예산 알림은 자동 중지가 아닙니다.
