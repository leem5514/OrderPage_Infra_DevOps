# Infra 문서 지도

이 폴더는 요구사항을 재정의한 이후의 문서입니다. `restart`라는 이름은 배포 재시작 명령을 뜻하지 않습니다. 처음부터 날짜순으로 읽을 필요 없이 아래에서 필요한 주제를 선택하세요.

| 알고 싶은 것 | 읽을 문서 | 이 문서가 답하는 질문 |
|---|---|---|
| 지금 어디까지 했나 | [진행 상태](project-process.md) | 완료한 일, 다음 단계, apply를 했는가 |
| 비용은 얼마나 드나 | [비용 예측·운영 계획](costs.md) | 48시간·8만 원 목표, 사양, 단가, 제외 비용, 정리 시점 |
| 무엇을 검사했나 | [통합 점검표](checks.md) | 통과 근거, 미검증 범위, 배포 전 남은 확인 |
| 어떻게 설정하나 | [실행 안내](guides/README.md) | 인증 → 인프라 → CI/CD → 모니터링 → 실험 |
| 왜 이 권한이 필요한가 | [IAM 설계](iam/README.md) | Role 분리, 권한 상한, OIDC, 서비스별 제한 |
| JSON은 무엇인가 | [가격 근거](pricing-evidence/README.md), [검증 근거](security-evidence/README.md) | 계산 입력인지 검사 결과인지, 어느 시점의 값인지 |

## 문서를 관리하는 기준

- **현재 상태는 진행 상태와 통합 점검표에 갱신합니다.** 날짜별 상태 보고서나 별도 재개 문서를 새로 만들지 않습니다.
- **비용 예측은 비용 문서 하나에 갱신합니다.** 단가 기준일·수량·사용량·제외 항목을 함께 수정합니다. 원본 단가 JSON은 계산의 재현을 위해 날짜별로 남깁니다.
- 실행 안내와 IAM 문서는 구성 이유·절차를 설명합니다. 작성 당시 테스트 수나 미완료 표시는 현재 상태가 아니므로 상단 안내와 통합 점검표를 먼저 봅니다.
- JSON은 도구가 읽을 수 있는 원본 근거입니다. 주석을 넣으면 표준 JSON이 아니게 되므로 같은 폴더의 README에 **모든 파일의 의미·용도·한계**를 적습니다. AWS 콘솔에 붙여 넣는 정책이나 Terraform 입력 파일이 아닙니다.
- 실제 키·계정 입력·state·plan·로그 원본은 이 폴더에 넣지 않습니다. 점검 통과는 모든 유출이나 공격 가능성이 없다는 보증이 아닙니다.

## 이번 정리에서 달라진 점

날짜별 비용 문서 2개는 비용 예측으로, 앱·비밀정보·보안·plan 보고서 11개는 통합 점검표로 묶었습니다. PR #23 시점에서 멈춘 재개 문서와 오래된 비용 계산기는 삭제했습니다. 현행 계산기는 `scripts/estimate-lab-costs.mjs` 하나를 사용합니다. 23개 상세 문서는 실행 안내와 IAM 폴더로 옮겼습니다.

기존 46단계 진행서는 현재 상태·핵심 이력으로 줄였습니다. 삭제 전 상세 설명은 [정리 전 문서 스냅샷](https://github.com/leem5514/OrderPage_Infra_DevOps/blob/0676378d1fb7b1f125172a9dd3a88c2c47c94108/docs/restart/)에 남아 있으며, 그 문서의 실행 순서·미완료 표시는 현재 지침으로 사용하지 않습니다. AWS·Terraform·애플리케이션 동작은 바꾸지 않았습니다.
